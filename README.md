## 2. Deskripsi Proyek

Website ini merupakan proyek mini individu UTS Pemrograman Web dengan tema **Jajanan Pasar**.

Website dibuat untuk menampilkan informasi dan katalog jajanan pasar secara sederhana dan dinamis menggunakan PHP. Data jajanan disimpan dalam array PHP dan ditampilkan melalui halaman katalog.

Proyek ini menerapkan HTML5 semantik, CSS, PHP dasar, array, perulangan, percabangan, dan fungsi sesuai dengan ketentuan UTS.
